## ❌ Hard Failures（致命问题）

### 1. 硬编码敏感密钥
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/OrchestrationMCPTest.java:60-64
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/OrchestrationMCPTest.java:104-110
- 说明: 测试类中直接写入真实 API Key，违反“禁止硬编码敏感密钥”规范，存在泄露风险。

### 2. Mockito.any 误用导致 Mock 失效
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/TestBeanConfig.java:48-57
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/TestBeanConfig.java:81-86
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/TestBeanConfig.java:99-104
- 说明: 将 Mockito.any(...) 赋值给变量后再传入 when，会变成对 null 参数的桩实现，实际调用非 null 参数时不会命中，可能导致 NPE 或测试失效。

### 3. OllamaTest 缺少测试 Profile 下的 Bean 定义
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/OllamaTest.java:81-85
- 说明: 测试环境启用 profile=test（src/test/resources/application.yml），但 VectorStoreConfig 在 test 下被禁用，且 TestBeanConfig 未提供 ollamaSimpleVectorStore/ollamaPgVectorStore，导致 Spring 上下文无法注入该依赖。

### 4. 使用 System.out.println 违反日志规范
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/MCPTest.java:110-125
- 文件: ai-mcp-knowledge-app/src/test/java/com/xbk/knowledge/test/MCPTest.java:150-165
- 说明: java-dev 规范明确禁止 System.out.println，应统一使用 Slf4j 日志。

## 🏗️ Architecture Review Findings（架构审查发现）

### 安全性
- 硬编码真实 API Key（OrchestrationMCPTest），高风险泄露点。

### 可靠性
- 多个测试依赖外部网络与真实服务，且默认执行，导致测试结果不稳定且可能产生副作用。
- Mock 桩实现失效导致测试行为不确定。

### 可维护性
- 过时测试类未隔离，且与当前编排层模式冲突，增加维护成本。
