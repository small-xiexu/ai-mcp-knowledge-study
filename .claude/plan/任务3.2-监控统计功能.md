- Service 层聚合业务逻辑
- Controller 暴露 4 个 REST API
- 统一 Result 包装返回

## 📦 DTO 设计

### 1. CallMetricsDTO - 调用次数统计
```
字段:
- totalCalls: Long - 总调用次数
- successCalls: Long - 成功次数
- failedCalls: Long - 失败次数
- fallbackCalls: Long - 降级次数
```

### 2. SuccessRateDTO - 成功率统计
```
字段:
- totalCalls: Long - 总调用次数
- successCalls: Long - 成功次数
- successRate: Double - 成功率百分比
```

### 3. ResponseTimeDTO - 响应时间统计
```
字段:
- avgResponseTime: Double - 平均响应时间（毫秒）
- maxResponseTime: Long - 最大响应时间（毫秒）
- minResponseTime: Long - 最小响应时间（毫秒）
```

### 4. ModelUsageDTO - 模型使用分布
```
字段:
- modelId: Long - 模型ID
- modelName: String - 模型名称
- callCount: Long - 调用次数
- percentage: Double - 占比百分比
```

## 🔧 Service 设计

### MetricsCollector

**职责**: 提供四类统计能力

**方法**:
1. `getCallMetrics(modelId, taskType, startTime, endTime)` → CallMetricsDTO
2. `getSuccessRate(modelId, taskType, startTime, endTime)` → SuccessRateDTO
3. `getResponseTimeMetrics(modelId, taskType, startTime, endTime)` → ResponseTimeDTO
4. `getModelUsage(startTime, endTime)` → List<ModelUsageDTO>

**处理逻辑**:
- 统一处理空参数
- 时间范围默认值处理
- 除零保护（成功率计算）
- 日志记录（查询维度、耗时）

---

## 🌐 Controller 设计

### MetricsController

**路径**: `/api/metrics`

**端点**:

1. **GET /api/metrics/calls** - 调用次数统计
   - 参数: modelId(可选), taskType(可选), startTime(可选), endTime(可选)
   - 返回: Result<CallMetricsDTO>

2. **GET /api/metrics/success-rate** - 成功率统计
   - 参数: modelId(可选), taskType(可选), startTime(可选), endTime(可选)
   - 返回: Result<SuccessRateDTO>

3. **GET /api/metrics/response-time** - 响应时间统计
   - 参数: modelId(可选), taskType(可选), startTime(可选), endTime(可选)
   - 返回: Result<ResponseTimeDTO>

4. **GET /api/metrics/model-usage** - 模型使用分布
   - 参数: startTime(可选), endTime(可选)
   - 返回: Result<List<ModelUsageDTO>>

**职责**:
- 参数接收与校验
- 调用 MetricsCollector
- Result 包装
- 日志记录（入参、耗时）

## 🗄️ Repository 扩展

### CallLogRepository 新增方法

**聚合查询方法**（使用 @Query）:

1. **调用次数统计**
   - 按状态分组聚合（SUCCESS, FAILED, FALLBACK）
   - 支持过滤: modelId, taskType, 时间范围

2. **成功率统计**
   - 总调用次数
   - 成功调用次数
   - 支持过滤: modelId, taskType, 时间范围

3. **响应时间统计**
   - AVG(responseTime)
   - MAX(responseTime)
   - MIN(responseTime)
   - 支持过滤: modelId, taskType, 时间范围

4. **模型使用分布**
   - 按 modelId 分组聚合
   - COUNT(*) 计算调用次数
   - 支持过滤: 时间范围

**返回方式**:
- 使用投影接口或 DTO 构造函数
- 避免返回 Object[]

## ⚠️ 关键考虑

### 性能优化
- **索引策略**: 确保以下索引存在
  - `(modelId, createdAt)`
  - `(taskType, createdAt)`
  - `(status, createdAt)`
  - `(createdAt)` - 单列索引

### 安全性
- **参数白名单**: 只接受预定义参数
- **日期范围校验**: 防止查询过大范围
- **SQL 注入防护**: 使用 @Query 参数绑定

### 扩展性
- **按维度拆分**: 每类统计独立方法
- **DTO 稳定边界**: 避免直接暴露数据库结构
- **后续扩展**: 新增指标只需扩展 Service 和 Repository
