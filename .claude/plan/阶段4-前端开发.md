## 📋 项目概览

### 核心目标
实现 AI 多模型编排系统的前端管理界面，提供模型配置、任务类型管理、监控统计等功能。

### 技术选型
- **框架**：Vue 3 (Composition API + `<script setup>`)
- **语言**：TypeScript
- **构建工具**：Vite
- **UI 组件库**：Element Plus
- **图表库**：ECharts
- **HTTP 客户端**：Axios
- **路由**：Vue Router
- **状态管理**：Pinia（按需使用）

### 步骤 3：封装 Axios 和 API 接口 ⏳

**目标**：统一 HTTP 请求处理和 API 接口定义

**文件**：`src/utils/request.ts`
```typescript
import axios, { AxiosInstance, AxiosRequestConfig, AxiosResponse } from 'axios'
import { ElMessage } from 'element-plus'

// 创建 Axios 实例
const service: AxiosInstance = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器
service.interceptors.request.use(
  (config) => {
    // 可以在这里添加 token
    return config
  },
  (error) => {
    return Promise.reject(error)
  }
)

// 响应拦截器
service.interceptors.response.use(
  (response: AxiosResponse) => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')
      return Promise.reject(new Error(res.message || '请求失败'))
    }
    return res
  },
  (error) => {
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)

export default service
```

**文件**：`src/types/api.ts`
```typescript
// 统一响应格式
export interface Result<T = any> {
  code: number
  message: string
  data: T
}

// 分页请求
export interface PageRequest {
  pageNum: number
  pageSize: number
  sortField?: string
  sortOrder?: string
}

// 分页响应
export interface PageResult<T> {
  records: T[]
  total: number
  pageNum: number
  pageSize: number
  totalPages: number
}
```

**文件**：`src/types/model.ts`
```typescript
// 模型配置
export interface ModelConfig {
  id: number
  modelName: string
  modelType: string
  baseUrl: string
  enabled: boolean
  priority: number
  capability: ModelCapability | null
  createdAt: string
  updatedAt: string
}

// 模型能力

  id: number
  maxInputTokens: number
  maxOutputTokens: number
  supportFunctionCalling: boolean
  supportVision: boolean
  supportStreaming: boolean
  qualityScore: number
}

// 模型配置请求
export interface ModelConfigRequest {
  modelName: string
  modelType: string
  apiKey: string
  baseUrl: string
  enabled: boolean
  priority: number
  capability?: {
    maxTokens: number
    qualityScore: number
  }
}
```

**文件**：`src/api/model.ts`
```typescript
import request from '@/utils/request'
import type { Result, PageRequest, PageResult } from '@/types/api'
import type { ModelConfig, ModelConfigRequest } from '@/types/model'

// 查询模型列表
export function listModels(params: PageRequest) {
  return request.get<Result<PageResult<ModelConfig>>>('/models', { params })
}

// 查询模型详情
export function getModel(id: number) {
  return request.get<Result<ModelConfig>>(`/models/${id}`)
}

// 创建模型
export function createModel(data: ModelConfigRequest) {
  return request.post<Result<ModelConfig>>('/models', data)
}

// 更新模型
export function updateModel(id: number, data: ModelConfigRequest) {
  return request.put<Result<ModelConfig>>(`/models/${id}`, data)
}

// 删除模型
export function deleteModel(id: number) {
  return request.delete<Result<void>>(`/models/${id}`)
}

// 启用模型
export function enableModel(id: number) {
  return request.put<Result<ModelConfig>>(`/models/${id}/enable`)
}

// 禁用模型
export function disableModel(id: number) {
  return request.put<Result<ModelConfig>>(`/models/${id}/disable`)
}
```

## 📌 技术要点

### 1. TypeScript 类型安全
- 所有 API 响应都有类型定义
- 使用 `interface` 定义数据结构
- 避免使用 `any` 类型

### 2. 组件化设计
- 页面组件放在 `views/` 目录
- 通用组件放在 `components/` 目录
- 每个页面的子组件放在 `components/` 子目录

### 3. API 封装
- 统一使用 Axios 实例
- 统一错误处理
- 统一响应格式

### 4. 响应式设计
- 使用 Element Plus 的栅格系统
- 适配不同屏幕尺寸

### 5. 性能优化
- 路由懒加载
- ECharts 按需引入
- 防抖和节流

## 🔍 注意事项

1. **API 地址配置**：确保 Vite 代理配置正确，后端服务运行在 `http://localhost:8080`
2. **CORS 问题**：如果遇到跨域问题，需要在后端配置 CORS
3. **Element Plus 按需引入**：可以使用 `unplugin-vue-components` 实现按需引入
4. **ECharts 主题**：可以自定义 ECharts 主题以匹配 UI 风格
5. **错误处理**：所有 API 调用都应该有错误处理逻辑
